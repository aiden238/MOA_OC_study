# Week 13 Implementation - RAG, Knowledge Graph, Wiki

Status: implemented and locally verified
Date: 2026-06-22

## Scope

Week 13 completes the Week 12 RAG knowledge panel, Knowledge Graph, graph-augmented retrieval, and Self-Updating Wiki MVP work as an integrated Web UI/API path.

## Backend

- `app/rag/knowledge_graph.py`
  - Builds category, document, and concept nodes from `data/rag_docs`.
  - Builds weighted `contains`, `implements`, and `related_to` edges.
  - Supports query highlighting, neighbor subgraphs, graph snapshots, and `expand_query_with_graph()`.

- `app/orchestrator/executor.py`
  - Applies graph-augmented query expansion before RAG retrieval.
  - Records graph usage in trace metadata: original query, expanded query, highlighted nodes, expansion terms, and subgraph.

- `app/wiki/pipeline.py`
  - Supports manual candidate intake, heuristic evaluation, YAML-front-matter document writing, pending state, approval/rejection, Chroma reindex attempt, and graph snapshot refresh.

- `app/web/server.py`
  - Exposes:
    - `GET /api/rag-knowledge`
    - `GET /api/knowledge-graph`
    - `GET /api/knowledge-graph/neighbors`
    - `GET /api/knowledge-graph/highlight`
    - `GET /api/wiki/status`
    - `GET /api/wiki/pending`
    - `POST /api/wiki/manual-candidate`
    - `POST /api/wiki/pending/{id}/approve`
    - `POST /api/wiki/pending/{id}/reject`

## Web UI

- RAG knowledge panel loads categorized docs and example questions from `/api/rag-knowledge`.
- Knowledge Graph panel renders D3 force-directed nodes/edges with category filtering, zoom/pan, node inspection, prompt fill, and query highlight.
- Response metrics panel shows RAG sources, MCP trace, and graph highlights when graph-augmented RAG is used.
- Wiki panel now supports:
  - status summary,
  - pending candidate list,
  - approve/reject buttons,
  - manual candidate submission form,
  - automatic refresh of status, pending list, RAG knowledge panel, and graph after approval.
